# قائمة الإطلاق — لا تعتبر جاهزاً للنشر حتى تكتمل

## المنتج

- [ ] الاسم النهائي بالعربية والكردية والإنجليزية إن لزم.
- [ ] شعار وأيقونة خاصة لكل تطبيق أو هوية موحدة واضحة.
- [ ] معرف Bundle ID / Application ID نهائي ومستقر.
- [ ] العربية والكردية السورانية مكتملتان لكل الشاشات ورسائل الأخطاء والإشعارات.
- [ ] اختبار RTL على أحجام أجهزة مختلفة، مع أحجام خط كبيرة وإمكانية الوصول.
- [ ] لا تُعرض ديون محل لمستخدم غير مرتبط به.
- [ ] لا تؤكد أي عملية دون موافقة الطرف المقابل.
- [ ] لا يمكن تعديل عملية مؤكدة أو حذف تاريخها.
- [ ] سقف الدين يطبق خادمياً وضمن معاملات ذرية.
- [ ] وضع القراءة فقط بعد انتهاء التجربة/الاشتراك يحافظ على كل البيانات القديمة.

## الخلفية والأمان

- [ ] Supabase Development وProduction منفصلان.
- [ ] جميع migrations مطبقة على قاعدة الاختبار والإنتاج.
- [ ] RLS مفعّل ومختبر على كل جدول.
- [ ] اختبارات تسرب البيانات بين المحلات والعملاء ناجحة.
- [ ] Edge Functions لا تحتوي ثغرات authorization.
- [ ] لا توجد مفاتيح سرية في Git أو ملفات Expo العامة.
- [ ] ضبط Google OAuth مع Supabase وإعدادات Google Cloud واختبار الدخول على Android فعلي.
- [ ] إعداد مزود SMTP إنتاجي ذي نطاق مرسل موثّق، وتحقيق إرسال البريد إلى مستخدمين خارج فريق المشروع.
- [ ] ضبط redirect URL `debtledger-merchant://**` ومراجعة تحويل رابط البريد/Google إلى جلسة Supabase آمنة.
- [ ] Email OTP rate limits وCAPTCHA/anti-abuse مضبوطون.
- [ ] اختبر وصول رابط/رمز البريد إلى حسابات مختلفة، ومنع التكرار والضغط المتسارع.
- [ ] نسخ احتياطي واستعادة مجرّبان.
- [ ] سياسة حذف الحساب وفترات الاحتفاظ معتمدة قانونياً.
- [ ] سجلات الأخطاء لا تحتوي OTP أو أرقاماً أو تفاصيل ديون.

## الاشتراكات

- [ ] منتجات Google الثلاثة منشأة والأسعار/الأسواق متحققة.
- [ ] منتجات Apple الثلاثة منشأة والأسعار/الأسواق متحققة.
- [ ] RevenueCat مربوط بدور صاحب المحل في تطبيق سِجل الموحد فقط؛ لا اشتراك مطلوب من العميل.
- [ ] Entitlement `merchant_pro` يعمل.
- [ ] Webhook Authorization والتحقق من حالة subscriber من الخادم يعملان.
- [ ] اختبار الشراء الأول، التجديد، الإلغاء، الانتهاء، فشل الدفع، الاستعادة.
- [ ] لا يحدث تحصيل بعد التجربة إلا بعد موافقة شراء واضحة.
- [ ] اختبار بلد متجر عراقي على Android وiOS، والتحقق من السعر المحلي.

## المتاجر والقانون

- [ ] سياسة الخصوصية منشورة على HTTPS وبالرابط نفسه في المتجرين.
- [ ] شروط الاستخدام منشورة.
- [ ] رابط حذف الحساب يعمل، وميزة الحذف داخل التطبيق تعمل.
- [ ] رابط الدعم الفني ورقم/وسيلة اتصال حقيقية.
- [ ] صفحة App Privacy في Apple دقيقة.
- [ ] نموذج Google Play Data Safety دقيق.
- [ ] تصنيف عمري وأسئلة المحتوى مكتملة.
- [ ] صور الشاشة والوصف وبيانات الاتصال مكتملة بالعربية، والكردية إذا تم إدراجها كلغة متجر.
- [ ] مراجعة محامٍ عراقي لعبارات إثبات الديون والخصوصية والاحتفاظ بالسجلات.
- [ ] لا يوجد ادعاء بأن السجل سند قضائي أو توقيع إلكتروني ملزم دون رأي قانوني.

## الاختبارات قبل الإرسال

- [ ] حسابا مراجعة فعليان ببريدين مستقلين وربط اختبار قابل للإعادة، دون أي وضع Demo أو بيانات وهمية داخل النسخة المرسلة.
- [ ] ملاحظات مراجعة تشرح تجربة 30 يوماً التي يمنحها الخادم وكيفية شراء الاشتراكات.
- [ ] TestFlight داخلي ناجح.
- [ ] Google Play Internal Testing ناجح.
- [ ] اختبار على جهاز Android حقيقي وجهاز iPhone حقيقي.
- [ ] لا يوجد Crash في Google OAuth/Email OTP/الإشعارات/الشراء.
- [ ] اختبار انقطاع الإنترنت أثناء إنشاء الطلب والرد عليه.
- [ ] اختبار التكرار Idempotency بعد إعادة المحاولة.
- [ ] اختبار حساب انتهى اشتراكه وحساب جديد وحساب عميل مجاني.
